# Requisitos del perfil y servicios del trabajador (CU-12)
- Permitir que una misma cuenta use las funciones de cliente y de trabajador sin mezclar permisos (RF-04).
- Consultar y actualizar los datos autorizados del perfil del trabajador (RF-05).
- Registrar y consultar las categorías de servicio que el trabajador habilita (RF-06).
- Conservar la fecha y el registro de las modificaciones relevantes del perfil (RF-07).
- Requerir una sesión válida para modificar el perfil.
- Mostrar carga, errores y resultado vacío.
